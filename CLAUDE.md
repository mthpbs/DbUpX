# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

DbUpX is a `netstandard2.0` library of extensions to [DbUp](https://github.com/DbUp/DbUp)
for filtering, ordering, and content-hash versioning of database upgrade scripts (SQL Server
and PostgreSQL). It ships to NuGet as `DbUpX.Reborn`.

**All guidance for this repo lives in [`AGENTS.md`](./AGENTS.md)** — build/test commands
(including single-test and integration-test setup), the architecture overview, coding
conventions, and CI/publishing. Refer to it.
